### Opengraph Images

My first very primitive approach to making an opengraph image was to have a string [buffer](https://github.com/karlseguin/buffer.zig), write an svg directly into it, and convert it to a png using `imagemagick`, since it only accepts png. This seemed very intuitive and I thought that svgs would not be that hard to build, since they have a fairy simple and straightforward syntax. Not to mention its easy to apply filters as well.

```zig
var buf = try Buffer.init(allocator, 100);

const svg =
    \\<svg width="300" height="170" xmlns="http://www.w3.org/2000/svg">
    \\ <rect width="150" height="150" x="10" y="10" rx="20" ry="20" style="fill:red;stroke:black;stroke-width:5;opacity:0.5" />
    \\</svg>
;
try buf.write(svg);
```

And for very simple images like this... it actually worked. Using [MagickWand](https://imagemagick.org/magick-wand/) (adorable name), it gave us a function to write it to a png. After some screwing around, I implemneted linear-gradients

```zig
const xy: [4]u32 = switch (direction) {
    .LeftToRight => .{ 0, 0, 100, 0 },
    .RightToLeft => .{ 100, 0, 0, 0 },
    .TopToBottom => .{ 0, 0, 0, 100 },
    .BottomToTop => .{ 0, 100, 0, 0 },
};

var buf: [256]u8 = undefined;
const s = try std.fmt.bufPrint(&buf, "<linearGradient id=\"background\" x1=\"{d}%\" y1=\"{d}%\" x2=\"{d}%\" y2=\"{d}%\">", .{ xy[0], xy[1], xy[2], xy[3] });
try self.defs_buf.write(s);

try self.defs_buf.write("<stop offset=\"0%\" stop-color=\"#77b6ed\" />");
try self.defs_buf.write("<stop offset=\"100%\" stop-color=\"#8be8a7\" />");

try self.defs_buf.write("</linearGradient>");
```

 ### Blurring

 To make the text on the image clearer, I implemented a basic box blur (sorry Gauss fans). Unlike Gaussian, every pixel in the window counts equally, and you average the pixels in the window. The size of the window is based on the radius we pass in:

```zig
const window = @as(u32, radius) * 2 + 1;

var i: i32 = -@as(i32, radius);
while (i <= radius) : (i += 1) {
    const xx: usize = @intCast(std.math.clamp(
        @as(i32, @intCast(x)) + i,
        0,
        WIDTH - 1,
    ));
    const p = row[xx];
    // ....
}
```

 We do two passes of blurring, the horizontal pass (look left and right of each pixel, out to radius pixels away, and then average) and a vertical pass, which is the exact same thing, but up and down. Once we get a 32-bit pixel p, we extract the `argb` values out of it, average them out and set them in the blur_buffer.

 ```zig
 a += (p >> 24) & 0xff;
 r += (p >> 16) & 0xff;
 g += (p >> 8) & 0xff;
 b += p & 0xff;

 blur_buffer[y * WIDTH + x] = ((a / window) << 24) | ((r / window) << 16) | ((g / window) << 8) |(b / window);
 ```

If I had to make it Gaussian blur, I had to add weights to the neighbours in the windows to make it look more smooth, but for now, I am more of less happy with this result.

### Dithering

Dithering is infact, a bit simpler to implement than blurring, we start by having a 4x4 matrix

```zig
const bayer4x4 = [4][4]u8{
    .{ 0, 8, 2, 10 },
    .{ 12, 4, 14, 6 },
    .{ 3, 11, 1, 9 },
    .{ 15, 7, 13, 5 },
};
```

And then we set the threshold of each pixel and offset using -

```zig
const threshold = bayer4x4[(y / dot_size) % 4][(x / dot_size) % 4];
const offset: i32 = @divTrunc((@as(i32, threshold) - 7) * @as(i32, strength), 2);
```

This makes some pixels get a positive nudge (brighter), some get a negative nudge (darker), depending on where they fall on in the stencil (4x4 matrix), which we can add back to the rgb values

```zig
r = std.math.clamp(r + offset, 0, 255);
g = std.math.clamp(g + offset, 0, 255);
b = std.math.clamp(b + offset, 0, 255);
```

### Text

I initially thought that I had to implement some complex text-wrapping mechanism for this but my job was made 100x easier after discovering [pangocairo](https://docs.gtk.org/PangoCairo/pango_cairo.html), which is a part of [Pango](https://www.gtk.org/docs/architecture/pango), a library for laying out and rendering text. All I had to do was set font, text, width, wrap mode and the library did the work for me.

```zig
c.pango_layout_set_font_description(layout, font_desc);
c.pango_layout_set_text(layout, text.ptr, @intCast(text.len));
c.pango_layout_set_width(layout, (WIDTH - 80) * c.PANGO_SCALE);
c.pango_layout_set_wrap(layout, c.PANGO_WRAP_WORD_CHAR);

c.cairo_move_to(self.cr, x, y);
c.pango_cairo_show_layout(self.cr, layout);
```

For loading the font, I had to use another library called [fontconfig](https://github.com/servo/libfontconfig/blob/master/fontconfig/fontconfig.h).

```zig
_ = c.FcConfigAppFontAddFile(c.FcConfigGetCurrent(), "static/_priv/geist.ttf");
const font_desc = c.pango_font_description_from_string("Geist Bold 48").?;
defer c.pango_font_description_free(font_desc);
```

### Other Utilities

1. I took this example straight from [cairo samples](https://www.cairographics.org/samples/clip_image/) to render a small pfp at bottom right.
2. Then I also made a function to make a render a grid, which just draws lines horizontally and vertically at a distance.

```zig
while (x <= WIDTH) : (x += grid_size) {
  c.cairo_move_to(self.cr, x, 0);
    c.cairo_line_to(self.cr, x, HEIGHT);
}

var y: f64 = 0;
while (y <= HEIGHT) : (y += grid_size) {
  c.cairo_move_to(self.cr, 0, y);
  c.cairo_line_to(self.cr, WIDTH, y);
}

c.cairo_stroke(self.cr);
```
